# Lista de requisitos de infraestrutura

- **SGBD:** MySQL Server 8.0 ou versão compatível com o Prisma Provider MySQL.
- **Linguagem de programação:** TypeScript 5.x; SQL para criação e população do banco.
- **Runtime:** Node.js compatível com Next.js 16.
- **Framework web:** Next.js 16.4.1, React 19.3.0.
- **ORM:** Prisma 5.22.x.
- **Sistema operacional de desenvolvimento:** Windows 10/11 64 bits (também pode ser executado em Linux ou macOS compatível com Node.js e MySQL).
- **Navegador cliente:** Google Chrome, Microsoft Edge ou Mozilla Firefox atualizados.
- **Hardware recomendado:** computador com processador dual-core ou superior, 4 GB de RAM (8 GB recomendados) e espaço para Node.js, dependências e MySQL.
- **Conectividade:** acesso local ao servidor MySQL; a variável `DATABASE_URL` deve apontar para o banco `saep_db`.
